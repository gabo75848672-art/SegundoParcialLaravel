# Backend Laravel (Empleados)
## Setup
1) Copia `.env.example` en `.env` y configura MySQL.
2) `composer install`
3) `php artisan key:generate`
4) `php artisan migrate --seed`
5) `php artisan serve --host=127.0.0.1 --port=8000`
## Endpoints
- GET  /api/empleados
- POST /api/empleados
- GET  /api/health
